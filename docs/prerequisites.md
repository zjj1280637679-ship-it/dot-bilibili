# 使用前提 / Prerequisites

**使用前，当前 GPT / dot 环境必须具备可用且已获授权的云浏览器，能够联网访问目标网站；同时启用插件并配置本地宿主运行时。仅打开一个“联网”开关，或仅安装插件，都不足以让它工作。**

不同 GPT 客户端和 dot 环境的功能并不相同；不能保证所有客户端都有云浏览器、Shell 或本插件所需的并发执行能力。

## 必需条件

1. **浏览器与网站连通性**：当前会话提供受支持的 dot 云浏览器工具，且目标网站可访问。遇到网站访问确认时，用户可以逐次批准。
2. **访问授权**：应用设置中的“云浏览器 → 权限 / 默认”控制访问网站前是否询问；它不是通用的互联网总开关。“始终询问”、适用的自动批准或逐站批准均可满足相应操作的授权需要。**不要求、也不建议为了本插件开启全局“始终允许（风险较高）”。**
3. **插件已启用**：安装并启用 `dot-bilibili` 的 `bilibili` skill，且当前会话能够发现、加载它。Skill 提供操作说明，不会创建浏览器权限或注册原生 MCP 函数。
4. **宿主已配置**：可用的 Shell、Python 3.12+、对应版本的源码或分发包、私有宿主绑定，以及原有规范路径下的运行时、数据库和 spool。宿主必须在 CLI 等待时并发处理受支持的浏览器操作。

## 不同权限不能混为一谈

- 云浏览器的网站访问批准 **不等于** Shell 的网络访问权限。
- 浏览器能打开网页 **不等于** 已授予任何平台 API 权限。
- 启用插件 **不等于** 已登录哔哩哔哩账号，也不提供账号凭据。
- 公开只读内容可能无需登录；若网站要求登录，须由用户在受支持的浏览器中自行完成。遇到登录、验证码、访问拒绝或权限缺失时停止并说明阻碍，不绕过验证。
- API 授权是独立事项；本插件不因获得网页访问权限而自动拥有 API 授权。

## 安装后的自检与停止条件

由可信宿主在绑定的规范运行时目录中执行：

```sh
python -m bili_distribution.cli diagnose
python -m bili_distribution.cli instructions
python -m bili_integration.cli schemas
python -m bili_video_reference.cli schemas
python -m bili_video_reference.cli instructions
```

检查输出指向的资源确实存在、哈希匹配、所需入口可用。`diagnose` 成功只证明本地资源可用，**不证明浏览器联网、网站授权、账号登录或业务读取成功**。浏览器连通性和当前页面/标签必须由受支持的宿主工具重新观察。

缺少模块、绑定、浏览器能力、Shell 能力或授权时，报告具体缺项并停止依赖它的操作。不要自动扩大权限、创建替代数据库、迁移旧账本、更换运行目录、绕过访问拒绝或反复重放不确定请求。不得要求用户公开私有绑定或凭据。
