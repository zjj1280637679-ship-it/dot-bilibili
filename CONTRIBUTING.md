# Contributing

Run the README's offline test, model and JavaScript checks before proposing a
change. Use synthetic fixtures only. Keep capabilities narrow and typed; preserve
fail-closed behavior, single-consumption navigation and unknown-result handling.
Do not weaken freshness, target, scope, budget or private-directory checks.

Do not submit cookies, QR challenges, browser captures, account identifiers,
private research, runtime databases/spools or third-party page/comment bodies.
Reproduce bugs with minimal synthetic inputs. Live browser/authentication work
requires separate explicit authorization; tests must remain offline by default.

Contributions must be your own work or otherwise legally redistributable, and
are submitted under this project's MIT license. Do not copy external project
code without documenting compatible licensing and required notices.
